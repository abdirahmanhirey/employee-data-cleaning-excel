# Employee Data Cleaning Project
## Project Overview
This project focuses on cleaning and improving the quality of an employee dataset using Microsoft Excel.
## Project Objectives
Identify missing values.
Check for duplicate records.
Standardise date formats.
Separate combined columns.
Identify unusual data values.
Document cleaning decisions.
## Tools Used
Microsoft Excel
Excel Filters
COUNTIF
COUNTA
UNIQUE
ABS
Paste Special (Values)
## Data Cleaning Tasks
Reviewed missing Age values.
Checked for duplicate employee records.
Standardised Join_Date formats.
Separated Department and Region.
Identified 24 N/A salary values and retained them pending investigation.
Flagged repeated email addresses for verification.
Converted negative phone values to positive numbers.

## Key Learning Outcomes
Improved Excel data-cleaning skills.
Practised identifying data-quality issues.
Learned to document cleaning decisions.
Preserved original data for comparison.
